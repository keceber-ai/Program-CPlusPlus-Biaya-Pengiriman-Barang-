# Program-C-Biaya-Pengiriman-Barang-
Program C++ sederhana untuk menghitung biaya pengiriman barang berdasarkan jenis layanan Regular atau Express dan berat paket. Program ini menggunakan variabel, input-output, percabangan switch-case dan if, serta operasi aritmetika untuk menghitung total biaya dan biaya tambahan paket di atas 10 kg.
